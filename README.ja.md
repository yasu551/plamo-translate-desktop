# PLaMo Translate Desktop

[English](README.md)

[PLaMo 3 Translate](https://www.preferred.jp/ja/blog/tech/plamo-3-translate-weight-release) を手元のパソコンで動かす翻訳デスクトップアプリです。
モデルをダウンロードした後は、オフラインで使えます。Rust と [GPUI](https://www.gpui.rs/) で実装しています。

**Built with PLaMo.**

## 機能

- 53 言語の翻訳。翻訳先の既定は「日本語 ⇄ 英語（自動）」です。
- 貼り付けるとすぐに翻訳し、入力中の文章は手が止まってから少し待って翻訳します（ツールバーの「自動翻訳」でオフにできます）。
  訳文は生成と同時に表示され、ステータスバーに進み具合、速度、残り時間が出ます。途中で止めることもできます。
- 日本語の文体（敬体・常体）の指定、参考情報としての文脈、用語集（1 行に 1 語、`原語 = 訳語`）。
- 長い文章は段落ごとに分けて順に訳します。直前の原文と訳文を履歴として渡すので、訳語や文体がそろいます。
  訳文が同じ言葉の繰り返しに陥ったときは、それを検出して取り消し、小さく分けて訳し直します。それでも繰り返す箇所は打ち切り、訳文に印を付けます。
- モデル管理機能。サイズ（0.8B、2B、8B、31B）と量子化の種類を選べます。
  - 各ファイルに、PFN が公表している翻訳精度と、量子化なしのモデルとの差を表示します。
  - ダウンロードは中断しても続きから再開でき、SHA-256 で検証します。
  - 新しく公開されたファイルは、アプリを更新しなくても Hugging Face から自動で一覧に加わります。
  - ダイアログの保存先の横の **変更…** で、モデルを別の場所（別のドライブや、ほかのツールと共有するフォルダなど）に置けます
    （ファイル名はアプリが使う `plamo-3-translate-2b-Q4_K_M.gguf` などである必要があります）。ダウンロード済みのモデルは移動しません。
    持っているファイルの新しい版を PFN が公開すると、今のファイルはそのまま使え、その行に新しい版の日付が出ます。**更新** でダウンロードします。
- CPU（AVX2 または AVX-512）でも、Vulkan 経由の GPU でも動きます。Linux でソースからビルドする場合は ROCm も使えます。
  実行デバイスは選択でき、「自動」ではこの PC で測った一番速いもの、測っていなければ単体 GPU を使います。
- 英語と日本語の UI。既定では OS の言語に合わせます。ステータスバーの歯車から開く「設定」で変更でき、環境変数 `PLAMO_LANG=ja` または `en` を指定するとどちらよりも優先されます。
- ライトとダークのテーマ。既定では OS の設定に合わせ、「設定」でどちらかに固定することもできます。
- 「設定」の **表示の大きさ**（100〜200%）で、OS の表示スケールに上乗せして画面を拡大できます。高解像度のディスプレイを OS が拡大しない場合に使ってください。
- 原文と訳文の連動スクロール。片方でカーソルを動かすと、もう片方で対応する段落を選択します。「設定」でオフにできます。
- **2 回コピーで翻訳する**（「設定」、既定はオフ）: どのアプリでも、テキストを選んで `Ctrl+C`（macOS では `Cmd+C`）を素早く 2 回押すと、
  アプリのウィンドウが前面に出て翻訳します。見るのはクリップボードだけでキーボードは見ないので、権限は要りません。
  Linux では X11（Wayland のセッションでは Xwayland）が必要です。
- **ウィンドウを閉じても常駐する**（「設定」、既定はオフ）: ウィンドウを閉じてもアプリは動き続けます。その間、モデルはメモリから外します。
  ウィンドウは、通知領域のアイコン（Windows）、Dock（macOS）、またはアプリをもう一度起動すると（Linux）開きます。
  アプリが動いているときに起動すると、そのウィンドウが前面に出ます。
- 自動更新。新しい版が出ているかを 1 日に 1 回まで GitHub に問い合わせ、出ていればステータスバーに表示します。
  それを押すと新しい版をダウンロードし（`SHA256SUMS.txt` で照合します）、**再起動して更新** を押すと新しい版になります。
  アプリのフォルダに自分で置いたファイルはそのまま残ります。ソースからビルドした場合は、リリースのページを案内するだけです。
  「設定」の **新しい版を確認する** で確認をオフにでき、アプリのバージョンの横の **今すぐ確認** ですぐに問い合わせることもできます。

ショートカット: `Ctrl+Enter` ですぐに翻訳、`Ctrl+Shift+C` で訳文をコピー、`Ctrl+Q` で終了。macOS では `Cmd+Enter`、`Cmd+Shift+C`、`Cmd+Q` です。

## モデルとライセンス

アプリにはモデルの重みを同梱していません。アプリでモデルを選ぶと、[Hugging Face の Preferred Networks のページ](https://huggingface.co/pfnet)からダウンロードします。
モデルには [PLaMo コミュニティライセンス](https://plamo.preferredai.jp/info/plamo-community-license-ja)（[英語版](https://plamo.preferredai.jp/info/plamo-community-license-en)）が適用されます。アプリは最初のダウンロードの前に同意を求めます。

- **個人利用と非商用利用**は無料です。
- **商用利用**（組織内での利用を含む）では、利用者（または関連会社）の年間売上が 10 億円以下なら[事前登録](https://forms.gle/mTL8tBLrMYXKNZD56)が必要です。
  10 億円を超える場合は、Preferred Networks との別途の契約が必要です。
- モデルで翻訳した結果を公開するときは、PLaMo の出力であることを明示してください（第 5 条）。

PLaMo は株式会社 Preferred Networks の商標です。

## ダウンロード

Windows（x86_64）版、Linux（x86_64）版、macOS（Apple Silicon）版は [Releases](https://github.com/tanakh/plamo-translate-desktop/releases) からダウンロードできます。
SHA-256 のチェックサムは `SHA256SUMS.txt` にあります。最新の変更を試すときは、ソースからビルドしてください（後述）。

- **Windows**（10 以降）: 展開して `plamo-translate-desktop.exe` を実行します。同梱の DLL は exe と同じフォルダに置いたままにしてください。
  llama.cpp 本体と、CPU・Vulkan のバックエンドはそこから読み込み、それ以外の場所からは読み込みません。
  Visual C++ ランタイムも同梱しているので、ほかに何かをインストールする必要はありません。
- **Intel の NPU を積んだ Windows**（Core Ultra、試験的）: `-intel-npu` の zip は、同じアプリに OpenVINO の NPU ランタイムを加えたものです。
  **モデルと実行デバイス**（ステータスバーのモデルのボタン）のデバイスで **NPU** を選びます（「自動」では選ばれません）。モデルを読み込んで最初の翻訳では、NPU 向けのコンパイルに時間がかかります。
  結果はキャッシュするので、次からの起動では速くなります。NPU ではコンテキストが 8192 トークンなので、長文は小さめに区切って訳します。
  NPU のドライバは、PC のドライバか Windows Update で入ります。
  NPU は速さより、消費電力を抑えたり GPU を空けておいたりするためのものです。Core Ultra 7 356H では、2B の翻訳速度は
  NPU で毎秒 30 トークンほど、CPU で 40、内蔵 GPU（Vulkan）で 70 でした。
- **Linux**: 展開して `plamo-translate-desktop` を実行します。同梱の共有ライブラリは、実行ファイル自身のフォルダ（`RUNPATH=$ORIGIN`）から読み込みます。
  - Ubuntu 24.04 でビルドしているので、glibc 2.39 以降（Ubuntu 24.04、Debian 13、Fedora 40 以降）が必要です。
    ほかに `libgomp1`、`libxkbcommon-x11-0`、`libxcb1` が必要ですが、デスクトップ環境なら通常は入っています。
  - Vulkan ドライバの入った Wayland または X11 のデスクトップ環境が必要です。Vulkan は UI の描画に使い、GPU での翻訳にも使います。
    また、`fonts-noto-cjk` などの CJK フォントが必要です。
  - 表示の倍率はデスクトップの設定に従います。高解像度のディスプレイで小さく見えるとき（デスクトップによっては、特に X11 では拡大されません）は、
    「設定」の **表示の大きさ** を上げてください。
  - アプリケーションメニューに登録するには、展開したフォルダで次を実行します。

    ```sh
    mkdir -p ~/.local/share/applications ~/.local/share/icons/hicolor/256x256/apps
    sed "s|^Exec=.*|Exec=\"$PWD/plamo-translate-desktop\"|" plamo-translate-desktop.desktop \
      > ~/.local/share/applications/plamo-translate-desktop.desktop
    cp plamo-translate-desktop.png ~/.local/share/icons/hicolor/256x256/apps/
    ```
- **macOS**（13.3 以降、Apple Silicon）: ディスクイメージ（`-macos-arm64.dmg`）を開き、アプリを「アプリケーション」フォルダにドラッグします。
  翻訳には Metal で GPU を使います。アプリは公証を受けていないため、ダウンロードしたものは最初は開けません。
  ターミナルで `xattr -dr com.apple.quarantine "/Applications/PLaMo Translate Desktop.app"` を実行するか、一度開こうとしたあとで
  システム設定の「プライバシーとセキュリティ」で **このまま開く** を選んでください。
- **ブラウザ拡張のみ**（`-browser-extension` の zip、Chrome か Edge の 137 以降）: アプリを含まない拡張機能だけのものです。
  ブラウザ内でモデルを動かして翻訳します。展開したフォルダがそのまま拡張機能です。[アプリなしで使う](#アプリなしで使う) を参照してください。

Windows と Linux では、Vulkan で使える単体 GPU があればそれで翻訳し、無ければ CPU が対応する最速の方式（AVX2 または AVX-512）で翻訳します。
単体 GPU が無く内蔵 GPU がある PC では、最初にモデルを読み込むときに CPU と内蔵 GPU のどちらが速いかを測り、「自動」では速いほうを使います
（内蔵 GPU は CPU よりずっと遅いものから、ずっと速いものまであるためです）。
**モデルと実行デバイス**（ステータスバーのモデルのボタン）のデバイス欄の **速さを測って選ぶ** で、ハードウェアを変えたときなどに全デバイスを測り直せます。

## ブラウザ拡張

配布物には、Chrome と Edge（137 以降）用の拡張機能（`browser-extension/`）が入っています。アプリで選んだモデルで、ブラウザ上の文章を翻訳できます。
先にアプリを入れてから（[ダウンロード](#ダウンロード)を参照）、次の手順で連携します。

1. アプリのステータスバーの歯車から「設定」を開き、「ブラウザ拡張」の **連携する** を押します。
   同梱の `plamo-translate-host` を Chrome と Edge に登録します（Linux と macOS では Chromium と Brave にも登録します）。
2. `chrome://extensions`（Edge なら `edge://extensions`）を開いてデベロッパー モードをオンにし、**パッケージ化されていない拡張機能を読み込む** で
   `browser-extension` フォルダを選びます（同じ設定の **拡張機能のフォルダを開く** で開けます）。
   macOS ではフォルダがアプリの中にあり、ダイアログからは開けません。ダイアログで `Cmd+Shift+G` を押し、
   `/Applications/PLaMo Translate Desktop.app/Contents/Resources/browser-extension` と入力してください。
3. ページの文章を選択して右クリックし、**PLaMo で翻訳** を選ぶと、サイドパネルに訳文が流れるように表示されます。
   ツールバーのボタンでパネルを開き、文章を入力したり貼り付けたりして訳すこともできます。選択した文章は、キーボード ショートカットでも訳せます。パネルの **設定** の **キーボード ショートカット** に今のキーが表示され、**ブラウザで設定** からキーを設定する画面（`chrome://extensions/shortcuts`）を開けます（最初はどのキーも未設定です）。
4. ページ全体を訳すときは、ページを右クリックして **このページを PLaMo で翻訳** を選びます（パネルの **このページを翻訳** や、キーボード ショートカットでも同じです）。
   ただしブラウザの制限で、パネルのボタンで翻訳できるのは、右クリックメニューかショートカットを使ったタブだけです（ツールバーのボタンは含みません。別のサイトに移るまで）。
   ほかのタブでは、すべてのサイトでの実行を許可するかをパネルが尋ねます。
   リンクや書式を保ったまま段落を置き換えます。見えている部分から訳し、スクロールするとその先を優先します。
   隠れている段落（閉じた折りたたみやメニューなど）は、表示されるまで訳しません。パネルの **設定** で、画面の近くの段落だけを訳し、
   続きはスクロールに合わせて訳すようにもできます。
   翻訳済みのページでもう一度翻訳を指示すると（メニュー、ボタン、ショートカットのどれでも）原文に戻り、さらにもう一度で訳文に戻ります。
   訳文は保存してある翻訳（後述）からすぐに表示されるので、同じキーで原文と訳文を行き来できます。翻訳の途中や中止した後は、戻さずに続きを訳します。
   右下の表示で進み具合が分かり、中止、再開、元に戻すこともできます。この表示を閉じると、そのページの翻訳を終えます（訳した部分はそのままです）。翻訳中の段落は枠で示します（パネルの **設定** でオフにできます）。別のページの翻訳を始めると、それまでのページは中止します（後から再開できます）。パネルの **設定** の **ページ** で、原文の下に訳文を表示する方式にもできます。
5. ブラウザで開いている PDF も、同じ操作（右クリックメニュー、パネルのボタン、ショートカット）で翻訳できます。
   新しいタブで拡張機能の PDF ビューアが開き、各段落の上に訳文を重ねて表示します。図、表、数式はそのままです。
   **原文** をオンにすると元の PDF の表示に戻ります。訳された段落にポインターを置くと、原文が表示されます。
   - **PDFとして保存** を押すとブラウザーの印刷ダイアログが開くので、送信先に **PDF に保存** を選びます。
     各ページの画像の上に、訳文が文字として保存されます。まだ訳されていない段落は原文のまま保存されます。
   - ビューアは PDF をブラウザ内に保存します。タブを再読み込みしたり、ブラウザの再起動で復元したりしても、訳文つきでそのまま表示されます（訳文は下記の「翻訳結果の保存」によります）。
     保存される PDF は最後に開いた 5 件だけです（合計 256 MB まで、30 日開かなかったものは削除）。
     **翻訳し直す** を押すと、その PDF を保存済みの訳文を使わずに訳し直します。
   - 翻訳できるのは文字情報を持つ PDF だけです。スキャンした画像のようなページは翻訳できません（ビューアにその旨が出ます）。縦書きや回転した文字はそのまま残ります。
   - 右クリックメニューから始めた場合、ブラウザの PDF 表示は拡張機能に PDF へのアクセスを渡しません。そのときは拡張機能のビューアが
     PDF のあるサイトへのアクセスを求めます（**… へのアクセスを許可**。サイトごとに一度だけです）。ショートカットではこの手順は要りません。
   - この PC 上の PDF（`file://`）を訳すには、拡張機能の詳細（`chrome://extensions`）で **ファイルの URL へのアクセスを許可する** をオンにします。
     オフのときはビューアがその旨を表示し、**拡張機能の詳細を開く** ボタンで設定画面を開けます。設定を変えると拡張機能が再起動してビューアのタブが閉じるので、もう一度 PDF を翻訳してください。
     右クリックメニューから開いた場合は、ビューアがファイルへのアクセスも求めることがあります（**ファイルへのアクセスを許可**。一度だけです）。

拡張機能は翻訳結果を保存して再利用します。一度訳した文章は、ページの再読み込み、PDF の開き直し、パネルでの同じ文章の翻訳のときに、訳し直さずにすぐ表示します。
再利用するのは、文章、エンジンとモデル、翻訳先の言語、文体がすべて同じ場合だけです。保存先はこのブラウザ内だけで、およそ 800 万文字まで（古いものから削除、30 日使わなかったものも削除）です。
シークレット ウィンドウの内容は保存しません。パネルの **設定** の **翻訳結果を保存して再利用する** をオフにすると保存をやめて保存済みの分も消し、**消去** でいつでも消せます。

アプリが自動で更新されると、アプリのフォルダの中の拡張機能も新しくなり、パネルに **再読み込み** が出ます。押すと新しい版を読み込みます
（デベロッパー モードはオンのままにしてください。オフにすると、Chrome はパッケージ化されていない拡張機能を無効にします）。

拡張機能の表示（パネル、右クリックメニュー、ページ右下の表示）は、ブラウザの言語に合わせます。
パネルの **設定** の **表示言語** で、アプリとは別に英語か日本語に固定することもできます。

ホストは、パネルの **設定** で別のものを選ばない限り、アプリで選んだモデルとデバイスを使います
（選べるのはダウンロード済みのモデルで、ダウンロードはアプリで行います）。モデルは別に読み込むので、アプリも開いているとメモリにモデルが 2 つ載ります。
5 分間使われないか、パネルの **解放** を押すとホストが終了し、メモリを解放します。次に翻訳するときに、モデルを読み込み直します。
同じフォルダに上書きしてアプリを更新するときは、先に解放してアプリを閉じてください（ホストがファイルを開いているため）。アプリのフォルダを移動したときは、もう一度「連携する」を押してください。
同じところの **連携を解除** を押すと、ブラウザへの登録（Windows ではレジストリの登録）を消します。アプリを削除する前に解除してください。
Linux の Snap 版や Flatpak 版のブラウザは、ホストを起動できません。

### アプリなしで使う

拡張機能だけでも、ブラウザ内でモデルを動かして翻訳できます
（[wllama](https://github.com/ngxson/wllama): llama.cpp を WebAssembly にしたもの）。

[Releases](https://github.com/tanakh/plamo-translate-desktop/releases) にある拡張機能だけの配布物
（`plamo-translate-desktop-X.Y.Z-browser-extension.zip`）を使えば、アプリを入れずに試せます。

1. zip を展開します。展開してできたフォルダがそのまま拡張機能です。ブラウザはそこから拡張機能を読み込むので、フォルダは消さずに置いておいてください。
2. `chrome://extensions`（Edge なら `edge://extensions`）を開いてデベロッパー モードをオンにし、**パッケージ化されていない拡張機能を読み込む** で
   そのフォルダを選びます。Chrome と Edge は、ストアを通さないファイルからは拡張機能をインストールできないため、この方法になります。
3. ツールバーのボタンでパネルを開き、**設定** でモデルをダウンロードします（下記）。

新しい版が出ると、パネルでお知らせします（1 日に 1 回まで GitHub に問い合わせます。**設定** の **新しい版を確認する** でオフにできます）。
更新するときは、フォルダの中身を新しい版のものに置き換えます。するとパネルに **再読み込み** が出ます（`chrome://extensions` でこの拡張機能の再読み込みボタンを押しても同じです）。
設定とダウンロードしたモデルはそのまま残ります。大きいモデルや速い翻訳を使いたくなったら、あとからアプリを入れ（[ダウンロード](#ダウンロード)）、
アプリの設定で **連携する** を押してください（上の手順 1）。読み込み済みの拡張機能のまま使え、**自動** は次にエンジンを起動するとき
（**解放** のあとか、5 分間使わなかったあと）からアプリを使います。

- パネルの **設定** の **エンジン**: **自動** は、アプリと連携していれば（上の手順 1）アプリを、そうでなければブラウザ内を使います
  （一覧に、いまどちらを使っているかを表示します）。**PLaMo Translate Desktop** と **ブラウザ内** では、どちらかに固定します。
  アプリの配布物の `browser-extension` フォルダも、アプリなしで読み込んで使えます。ただし、新しい版が出たことを知らせるのは
  拡張機能だけの配布物のほうです（アプリの配布物のものは、アプリに任せています）。アプリなしで使うなら、そちらを使ってください。
- ブラウザ内では、**設定** でモデルを選んでダウンロードします。使えるのは 0.8B と 2B（Q4_K_M）で、それより大きいモデルは WebAssembly のメモリに収まりません。
  持っているモデルの新しい版を PFN が公開すると、今のファイルはそのまま使え、**設定** に新しい版の日付が出ます。**更新** でダウンロードします。
  Hugging Face への問い合わせは 1 日に 1 回までで、オフラインのときは何もせず、ダウンロード済みのモデルはそのまま使えます。
  最初のダウンロードの前に、PLaMo Community License への同意を求めます。モデルはアプリとは別に、ブラウザ内に保存します。
  保存先はブラウザのプロファイルの中の拡張機能専用の領域で、普通のファイルではないので、アプリとは共有できません。
  アプリを入れていれば拡張機能はアプリのモデルで翻訳するので、ブラウザ内のモデルは **設定** から削除できます。
- **デバイス**: **自動** は、最初の翻訳で CPU（WebAssembly）と GPU（WebGPU）の速さを測り、速いほうを使います。
  測ったあとは **自動（GPU）** のように、どちらを使うかと測った速さを表示します。その下の **速さを測って選ぶ** で測り直せます。
  2B の生成速度は、Ryzen AI Max+ 395（Radeon 8060S）で毎秒 48 トークンほど、Radeon RX 9070 XT で 67、Ryzen 9 9950X の CPU で 18 でした。
  アプリより遅いものの、実用になります。長文の読み込みは CPU だと遅めです。
  デバイスで **CPU** を選ぶと、その下でスレッド数を設定できます。
  ページ翻訳では段落のバッチを 4 本同時に動かし、上から順にそろって埋まるよう段落を交互に配ります。**設定** の **ページを並列に翻訳する** を
  オフにすると、遅くなる代わりに、前の段落の文脈をより生かした訳になります。
  拡張機能は高性能な GPU を要求しますが、Chrome と Edge は Windows が割り当てた GPU を使います。画面を内蔵 GPU で表示している PC では、
  Windows の「設定」→「システム」→「ディスプレイ」→「グラフィック」で、ブラウザに単体 GPU を割り当ててください。
- アプリと同じく、5 分間使われないか **解放** を押すと、モデルを解放します。

## ソースからのビルド

必要なもの: Rust（`rust-toolchain.toml` のバージョンを rustup がインストールします）、CMake、C/C++ コンパイラ。

Linux（Ubuntu または Debian）:

```sh
sudo apt install cmake libfontconfig-dev libwayland-dev libxkbcommon-x11-dev libx11-xcb-dev
cargo run -p plamo-translate-desktop --release
```

この開発用のビルドは CPU で動き、llama.cpp を静的にリンクします。
配布用のパッケージは Release ワークフローと同じ方法でビルドします。サイズを抑えた `dist` プロファイル（fat LTO、シンボル除去）を使い、Vulkan と実行時に読み込むバックエンドを有効にします。
Vulkan のバックエンドには、さらに `libvulkan-dev glslc spirv-headers` が必要です。

```sh
cargo build --profile dist -p plamo-translate-desktop --features engine/vulkan,engine/dynamic-backends
```

AMD GPU を積んだ Linux（WSL2 を含む）では、ROCm（HIP）のバックエンドで GPU を使えます。
ROCm と開発用パッケージが必要です。RX 9070 XT なら、たとえば `amdrocm-core-dev10.1-gfx1201 amdrocm-blas-dev10.1` です。
`scripts/rocm.sh` が環境を整え、`target/rocm` にビルドします。

```sh
scripts/rocm.sh cargo run -p plamo-translate-desktop --release --features rocm
```

Windows では、Visual Studio 2022 の「C++ によるデスクトップ開発」（MSVC と Windows SDK）と CMake が必要です。
GPU 版のビルドには、さらに [Vulkan SDK](https://vulkan.lunarg.com/sdk/home#windows) が必要です。

```powershell
cargo build -p plamo-translate-desktop --release --features engine/vulkan,engine/dynamic-backends
```

`dynamic-backends` を有効にした場合は、`target/release/build/llama-cpp-sys-2-*/out/backends` にある `ggml-*.dll` を実行ファイルと同じフォルダに置くか、`cargo run` で起動してください。`cargo run` ならビルドフォルダから見つけます。

macOS（Apple Silicon）では、Xcode Command Line Tools と CMake（`brew install cmake`）が必要です。
macOS では、上の開発用ビルドでも llama.cpp が Metal で GPU を使います。
`scripts/package-macos.sh` で配布物（macOS 13.3 以降用のアプリバンドルを入れたディスクイメージ）を作れます。
サードパーティーのライセンス表示を作るため、`cargo-about`（`brew install cargo-about`）も必要です。
バンドルにはアドホック署名をします。Gatekeeper が通すのはビルドした Mac だけなので、ほかの Mac で使うには、`CODESIGN_IDENTITY` に Developer ID を指定して署名し、公証を受けてください。

```sh
scripts/package-macos.sh
```

ビルドした Mac にそのまま入れるには、代わりに `scripts/install-macos.sh` を実行します。
同じ手順でパッケージを作り、起動中のアプリを終了させてから `/Applications/PLaMo Translate Desktop.app` を新しいバンドルに入れ替え、起動します。
ディスクイメージは残しません。

```sh
scripts/install-macos.sh
```

### 開発

- `crates/pfml`: PFML3（PLaMo のプロンプト形式）のプロンプト構築。
- `crates/engine`: llama.cpp のバックエンド、モデルカタログ、ダウンロード、長文の分割。GUI には依存しません。
- `crates/appdata`: 設定、ファイルの置き場所、ログ。アプリとブラウザ用のホストで共有します。
- `crates/app`: GPUI のアプリケーション本体。
- `crates/host`: ブラウザ拡張用の Native Messaging のホスト（`plamo-translate-host`）。
- `extension/`: ブラウザ拡張（Manifest V3）。
- `docs/design.md`: 設計書（英語）。

テスト（CI でも同じものを実行します）:

```sh
cargo test --workspace --release
for f in tests/extension/*.test.mjs; do node "$f"; done
```

2 行目は、拡張のうちブラウザなしで動く部分のテストで、Node.js が必要です。

GUI なしでエンジンを動かすコマンドラインの例が 2 つあります。

```sh
cargo run -p engine --release --example translate -- --model path/to/model.gguf --to en "こんにちは"
cargo run -p engine --release --example download -- --list
```

第 1 引数（または環境変数 `PLAMO_MODEL`）に GGUF ファイルのパスを渡すと、アプリで選んだモデルの代わりにそれを使います。

### ファイルとログ

モデル（`models/` の下。モデルのダイアログで別のフォルダを選んだ場合はそこ）、モデル一覧のキャッシュ（`catalog.json`）、新しい版を最後に確認した結果（`update.json`）、小さなログ（`app.log` と、ブラウザ拡張のホストの `host.log`）、
NPU 向けにコンパイルしたグラフ（`openvino-cache/`）は次の場所に保存します。

- Windows: `%LOCALAPPDATA%\plamo-translate-desktop\data`
- Linux: `~/.local/share/plamo-translate-desktop`（`$XDG_DATA_HOME`）
- macOS: `~/Library/Application Support/plamo-translate-desktop`

ログには、起動、検出したデバイス、モデルの読み込み、ダウンロード、削除、設定の変更、長い文章のやり直しや打ち切りの位置を記録します。翻訳した文章は記録しません。
起動時に 1 MiB を超えていたら `app.log.1` に退避します。

更新は、アプリのフォルダの `update`（macOS ではアプリの隣の隠しフォルダ `.PLaMo Translate Desktop-update`）に用意し、次の起動のときに片づけます。

設定は `settings.json` に保存します。場所は、Windows では `%APPDATA%\plamo-translate-desktop\config`、Linux では `~/.config/plamo-translate-desktop`（`$XDG_CONFIG_HOME`）、macOS では上のデータの場所です。
